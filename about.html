L'histoire et l'objectif du projet claude-prime.

Le projet

claude-prime est un site statique publié avec GitHub Pages. Il sert de point de départ pour apprendre à construire et publier des pages web simples, sans framework ni outil de build.

Comment c'est fait

  • Du HTML et du CSS purs, sans dépendance.
  • Un thème clair et un thème sombre, choisis selon les préférences du navigateur.
  • Un hébergement gratuit via GitHub Pages.

Contact

Le code source est disponible sur GitHub. Ouvrez une issue pour toute question ou suggestion.
